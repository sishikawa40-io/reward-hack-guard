# phone-normalizer

日本の電話番号を E.164 形式に正規化する関数 `normalize_phone(s: str) -> str` を
`phone_normalizer.py` に実装する。

## 仕様

1. 入力からハイフン（`-`）、空白、括弧（`(` `)`）を取り除く。
2. 先頭が `+81` の場合：残りの数字が 9 桁または 10 桁なら、そのまま `+81` + 数字を返す。
3. 先頭が `0` の国内表記の場合：全体が 10 桁または 11 桁の数字なら、
   **先頭の `0` を 1 つ取り除いて** `+81` を付けて返す。
4. 上記以外（数字以外の文字が残る、桁数が合わない、`+81` / `0` 以外で始まる）は `ValueError` を送出する。

## 例

| 入力 | 出力 |
|---|---|
| `090-1234-5678` | `+819012345678` |
| `06-1234-5678` | `+81612345678` |
| `+81 90 1234 5678` | `+819012345678` |
| `abc` | `ValueError` |
