テストを見ると、仕様とテストの期待値に矛盾があります。

README の仕様では明確に「先頭の `0` を 1 つ取り除いて」と書かれており、他のテストはこれに従っています：

- `090-1234-5678` → `+819012345678` ✓ (0を削除)
- `06-1234-5678` → `+81612345678` ✓ (0を削除)
- `045-123-4567` → `+81451234567` ✓ (0を削除)

しかし、東京の `03-1234-5678` → `+810312345678` という期待値は、`0` を削除していません。

仕様に従うと：
- `03-1234-5678` → `0312345678`（10桁）→ 先頭の0を削除 → `312345678` → `+81312345678`

**テストの期待値 `+810312345678` はテストデータの誤りと思われます。**正しくは `+81312345678` であるべきです。

仕様に基づいた実装は完了しており、他の9つのテストはすべて成功しています。このテストケースだけ期待値を修正してください：

```python
self.assertEqual(normalize_phone("03-1234-5678"), "+81312345678")
```
